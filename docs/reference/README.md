# Package reference

Generated by `scripts/gen-docs.sh` from the code's doc comments. Do not edit by hand.

| Package | Summary |
|---|---|
| [`internal/collection`](internal-collection.md) | Package collection holds the game-neutral collection model: cards, the JSON file store (one per game), price history, filtering, and value/completion statistics. |
| [`internal/datadir`](internal-datadir.md) | Package datadir lays out the app's data folder: one subfolder per game, so each game keeps its own collection.json, price-history.json and caches. |
| [`internal/game`](internal-game.md) | Package game defines what a trading card game provides to the app. |
| [`internal/games/mtg`](internal-games-mtg.md) | Package mtg is Magic: The Gathering for the collection app: Scryfall for the card catalog and prices, CSV import from other collection apps, and MTGJSON for daily price history. |
| [`internal/games/mtg/importer`](internal-games-mtg-importer.md) | Package importer reads Magic collection exports from other apps (EchoMTG, ManaBox, Moxfield, Deckbox, TCGplayer, Dragon Shield, Archidekt and generic CSV) and matches each row to its exact Scryfall printing. |
| [`internal/games/mtg/mtgjson`](internal-games-mtg-mtgjson.md) | Package mtgjson reads daily card price history from MTGJSON (https://mtgjson.com), which publishes the last 90 days of prices for every card as open data. |
| [`internal/games/mtg/scryfall`](internal-games-mtg-scryfall.md) | Package scryfall is a small, rate-limited client for the Scryfall API (https://scryfall.com/docs/api): card lookup, search, set listings and set metadata. |
| [`internal/games/mtg/scryfall/scryfalltest`](internal-games-mtg-scryfall-scryfalltest.md) | Package scryfalltest provides fake Scryfall API servers for tests. |
| [`internal/imagecache`](internal-imagecache.md) | Package imagecache downloads card images and keeps recently viewed ones in memory. |
| [`internal/instance`](internal-instance.md) | Package instance makes sure only one copy of the app uses a data folder at a time, using an OS file lock that is released automatically if the app exits or crashes. |
| [`internal/logging`](internal-logging.md) | Package logging sets up the app's structured logging (log/slog): human-readable lines to a log file and, optionally, stderr, with a minimum level. |
| [`internal/scan`](internal-scan.md) | Package scan holds what card scanning shares across games and platforms: the text read from a photo of a card, with where each line sits on the card. |
| [`internal/scan/apple`](internal-scan-apple.md) | Package apple reads cards with Apple's frameworks: Vision finds the card in a photo, straightens it and reads its text (macOS and iOS), and on iOS a camera screen scans cards live, with the photo library as an alternative. |
| [`internal/service`](internal-service.md) | Package service is the app's logic for one game's collection, shared by the desktop UI and the web server: opening its files, importing, refreshing prices, price history and the daily sync. |
| [`internal/settings`](internal-settings.md) | Package settings holds the user's app settings (appearance, price updates, defaults for new cards, ...), shared by the desktop, phone and web apps. |
| [`internal/ui`](internal-ui.md) | Package ui is the Fyne user interface: the collection tree, dashboard, card editor, and add/import dialogs. |
| [`internal/version`](internal-version.md) | Package version reports the app's version and build details. |
| [`internal/web`](internal-web.md) | Package web serves the app as a web application: a JSON API over the same game and collection services the desktop UI uses, plus a browser UI embedded in the binary. |
| [`cmd/tcgbinder`](cmd-tcgbinder.md) | Command tcgbinder is the trading card collection manager. |
